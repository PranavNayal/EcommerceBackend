# E-Commerce Backend API

A minimal e-commerce backend application built using **Spring Boot** and **MongoDB** as part of an academic assignment.  
The project implements core e-commerce functionalities such as product management, cart operations, order processing, and basic payment handling.

---

## Features

- Create and list products
- Add products to cart
- View and clear cart
- Create orders from cart
- Basic (mock) payment processing
- MongoDB-based data persistence

---

## Tech Stack

- **Language:** Java  
- **Framework:** Spring Boot  
- **Database:** MongoDB  
- **Build Tool:** Maven  

---

## Project Setup

### Prerequisites
- Java 17+
- Maven
- MongoDB
